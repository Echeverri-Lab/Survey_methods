# Step 03 — Finding appropriate psychometric scales

This folder is for locating validated scales, documenting reliability/validity evidence, and storing scale items.

Folder structure:
- `scales_reference_table.md` — Reference table of validated scales (the canonical version; renders on GitHub).
- `psychometric_scales_socioecological.html` — Interactive, filterable version of the scales table. Download and open in a browser; GitHub displays .html files as source code.
- `papers/` — psychometric validation studies
- `templates/` — scale documentation template (items, scoring, reliability from pilot)
- `notes.md` — decisions and equivalence across populations

## Fillable PDF versions of the templates

Every template in this folder also comes as a fillable PDF next to the Markdown file. You do not need GitHub or Markdown to use them: open the PDF link below, click the download button, fill it in with the free Adobe Acrobat Reader (macOS Preview and web browsers also work), save, and attach it to your assignment.

| Template | Markdown source | Fillable PDF |
|---|---|---|
| Scale documentation template | [`templates/scale_documentation_template.md`](templates/scale_documentation_template.md) | [`scale_documentation_template.pdf`](templates/scale_documentation_template.pdf) |

*The PDFs are generated from the Markdown with [`tools/make_fillable_pdfs.py`](../tools/make_fillable_pdfs.py); edit the Markdown, then rebuild the PDFs.*
